## 1. Altium 原理图 ↔ 固件 GPIO / 供电 / 继电器 一致性核对

核对依据：原理图由 `simulation/gen_altium_schdoc.py` 生成（其 `nets` 网表与 `firmware/Core/Inc/main.h` 引脚宏严格对应），已在 Altium 中编译通过（0 Error）。

| 功能 | 固件引脚 (`main.h`) | 原理图网络 | 连接对象 | 结论 |
|---|---|---|---|---|
| NTC 温度采样 | `PA0` (ADC1_IN0) | `NTC_ADC` | R4(10k上拉) ↔ RT1(NTC) 分压点 | ✅ 一致 |
| 蜂鸣器驱动 | `PA1` | `BUZ_CTRL` → R5 → Q1(B) | S8050 低边驱动 BZ1(3V3) | ✅ 一致 |

### 1.2 供电树与驱动逻辑核对

| 项目 | 原理图实现 | 固件假设 | 结论 |
|---|---|---|---|
| 电源路径 | USB 5V → AMS1117-3.3 → `3V3` | `3V3` 为 MCU/INA219/OLED/ESP 主电 | ✅ 一致 |
| 继电器线圈电源 | K1 线圈接 `+5V`，Q2 低边到 GND | `RelayOn()` 置 `PA2=高` → Q2 导通 → 线圈得电 | ✅ 一致（高电平吸合） |
| 续流二极管 | D1 阳极接线圈低边(A2)、阴极接 `+5V` | — | ✅ 方向正确（关断时钳位） |
| 蜂鸣器 | BZ1+ 接 `3V3`，BZ1- 经 Q1 到 GND | `BuzzerOn()` 置 `PA1=高` 鸣响 | ✅ 一致（低边驱动） |
| 分流采样 | R1(0.1R) 串入 `+5V` 负载回路，INA219 `VIN+`/`VIN-` 跨接 | `R_SHUNT=0.1R`, Cal=4096, LSB=0.8mA | ✅ 一致 |
| INA219 供电 | `VS` 接 `3V3`（独立于被测 5V 母线） | I2C 器件地址 0x40 | ✅ 一致 |

### 1.3 ⚠️ 需复核的设计项（非阻断，建议答辩前澄清）

1. **过压阈值与母线电压不匹配**：固件 `OV_VOLTAGE_THRESHOLD=21.0V`，但原理图采样点为 **5V USB 母线**。对 5V 系统而言 21V 过压保护实际永不触发。若本设备目的是监控更高电压电池组，应改采样点为电池端并把阈值设为对应额定值；若确为 5V 母线，建议将阈值改为 ~6.0V。请在实物前确认并同步修改 `main.h`。
2. **有源蜂鸣器由 3V3 驱动**：若所选蜂鸣器额定 5V，3V3 下可能声压不足或不响，建议确认器件规格或改由 5V 经三极管驱动（注意电平匹配）。
3. **继电器负载侧耐压**：K1 触点容量需 ≥ 实际负载电流/电压，原理图为 5V 低压负载示意，接真实电池负载前核对触点规格。

## 2. 低压实物测试方案（Point 5）

> 说明：以下为可操作的低压（≤ 安全特低电压 SELV，建议 ≤ 12V）验证步骤。**当前环境无法执行物理测试**，本方案供用户在具备硬件与可调电源时按序执行；所有步骤均以“先软件确认、再带电”为原则。

### 2.1 前置（编译已通过）
- 固件已用 Arm GCC 真实编译：`firmware/GCC_BUILD/build/firmware.bin`（17772 B，0 警告）。
- 保护逻辑已通过 C 单元测试（`tests/protect_tests.c`，详见 `run_tests.py` 的 TC08）。

### 2.2 上电与通信（不接负载）
1. 仅接 USB 5V 与 SWD/串口，不接功率负载；用 5V 限流电源（≤ 0.5A）供电。
2. 确认 OLED 显示 `SELF-TEST...` 后进入 `CHARGE MONITOR` 主界面；若 OLED 缺失，固件以 `oled_ok=0` 跳过渲染，不阻塞主循环（已验证）。
3. 串口/逻辑分析仪确认 I2C 总线（PB6/PB7）有 100kHz/400kHz 波形，INA219、SSD1306 地址应答。

### 2.3 采样准确性（低压）
4. 用可调电源在采样点注入已知电压，记录 OLED 显示 `V`/`A`/`W` 与 NTC 温度，对照万用表：误差应 ≤ INA219 LSB（电压 4mV、电流 0.8mA）与 NTC ±0.5℃。

### 2.4 保护动作（关键，低压模拟）
5. **过温切断**：将 NTC 靠近热源（或临时改 `TEMP_CUTOFF_THRESHOLD` 为可触发值）使温度越过阈值，确认继电器断开、蜂鸣器响、状态变 `CUT`。
6. **过流切断**：在分流回路串入可调负载使电流越限，确认同上。
7. **传感器故障切断**：断开 INA219 或 NTC 任一，确认立即 `CUT`；恢复连接后**自动恢复吸合**（传感器故障恢复路径，已单测覆盖）。
8. **阈值闭锁与显式恢复**：触发阈值切断后回到安全态，确认仍保持 `CUT`（闭锁）；通过远程/本地复位指令调用 `Protect_Recover()` 解除，确认恢复吸合并再次越限会重新切断（安全门卫，已单测覆盖）。

### 2.5 安全边界
- 全程使用限流电源；继电器负载端仅在确认保护动作正确后再接真实电池。
- 任何冒烟/过热立即断电；续流二极管 D1 方向、Q2 极性需先用万用表蜂鸣档确认。
- 低压测试通过且阈值/蜂鸣器规格复核无误后，方可升级到标称电压做最终验收。
