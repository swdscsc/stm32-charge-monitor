## 1. Altium 原理图 ↔ 固件 GPIO / 供电 / 继电器 一致性核对

核对依据：原理图由 `simulation/gen_altium_schdoc.py` 生成，其 `nets` 网表与 `firmware/Core/Inc/main.h` 引脚宏严格对应。本机 Altium 17.0 对 Rev.B 工程实测 `Compile successful, no errors found.`（0 error），`.PrjPcbStructure` 记录 `TopLevelDocument=charge_monitor.SchDoc`；Rev.B 曾有约 97 条 Floating 类 Warning，其引脚电气热点根因已在 Rev.C 修复并由 TC09 静态验证，**修复后的 GUI 复编译与 ERC 尚未执行**，详见 `docs/硬件原理图说明.md §9`。生成器内置**电气完整性自检**：每个符号引脚必须恰好归属一个网络，禁止未连接引脚、重复归属与单引脚网络（Rev.A 曾漏接 `U2.VBUS` 而未被发现，现已固化为生成期断言）。

### 1.2 供电树与采样回路核对（Rev.B 已分离）

| 项目 | 原理图实现 | 固件假设 | 结论 |
|---|---|---|---|
| **① 逻辑供电** | `J1` USB 5V → `+5V` → AMS1117-3.3 → `+3V3` | `3V3` 为 MCU/INA219/OLED/ESP 主电 | ✅ 独立，不串分流电阻 |
| **② 被测回路** | `J6` DC IN 5–20V → `VIN_DC` → R1(0.1R/2W) → `SHUNT_N` → K1.COM/NO → J4 负载 | `OV_VOLTAGE_THRESHOLD=21V` 对应 20V 额定测试点 | ✅ **Rev.B 修正** |
| **共地** | `J6.V-` 与 `J1.GND` 同接 `GND` | INA219 的 VBUS 为对 GND 单端测量，必须共地 | ✅ 一致（仅限隔离低压直流） |
| **INA219 VBUS** | `U2.VBUS` 接 `VIN_DC`（分流电阻**电源侧**） | 总线电压寄存器才有有效输入 | ✅ **Rev.B 补齐（Rev.A 缺此引脚）** |
| INA219 电流采样 | `U2.VIN+`→`VIN_DC`、`U2.VIN-`→`SHUNT_N` 跨 R1 | `R_SHUNT=0.1R`, Cal=4096, LSB=0.8mA | ✅ 一致 |
| INA219 器件供电 | `U2.VS` 接 `+3V3` | I2C 器件地址 0x40 | ✅ 一致 |
| 继电器线圈电源 | K1 线圈接 `+5V`，Q2 低边到 GND | `RelayOn()` 置 `PA2=高` → Q2 导通 → 线圈得电 | ✅ 一致（高电平吸合，待实物复核触发电平） |
| 续流二极管 | D1 阳极接线圈低边(A2)、阴极接 `+5V` | — | ✅ 方向正确（关断时钳位） |
| 蜂鸣器 | BZ1+ 接 `+3V3`，BZ1- 经 Q1 到 GND | `BuzzerOn()` 置 `PA1=高` 鸣响 | ✅ 一致（低边驱动） |

**为什么 VBUS 取电源侧而不是负载侧**：若接在 `SHUNT_N`（负载侧），继电器一旦断开，VBUS 会读到 0V，而保护逻辑的 `valid()` 允许 0V、电流也是 0 → 会被判为"安全"→ 传感器故障类切断会自动重合闸 → 重新读到真实过压 → 再次切断，形成**断开/吸合振荡**。取 `VIN_DC` 可保证切断后仍能监测真实输入电压。

### 1.3 关于 21V 过压阈值（订正 Rev.A 的误判）

Rev.A 文档曾建议"采样点是 5V USB 母线，21V 永不触发，应改为 ~6V"。**这个建议是错的，不要采纳**：

- `DESIGN.md §1` 明确 FR-1 按 **20V / 2.5A 作为保守测试点**，`TESTS.md` 的回归真值覆盖 5/9/12/15/20V，系统定位是监测**快充头/电池组的可变低压直流输出**，不是监测 MCU 自身的 5V 供电。
- `21V = 20V 额定 + 1V 余量`，且低于 INA219 的 **26V 器件上限**（`protect.c: valid()` 与 `ina219.c` 均按 26V 拦截），有 5V 器件余量，设定合理。
- **真正的问题在硬件侧**：Rev.A 原理图把 J1(USB 5V)、AMS1117 输入、R1、U2.VIN+ 全挂在同一个 `+5V` 网络，被测回路实际只能是 5V，且 U2 连 VBUS 引脚都没画。因此 21V 阈值在当时确实形同虚设 —— 但**降阈值会把 9/12/15/20V 的正常工况全判为过压**，等于毁掉功能。
- **Rev.B 的正确修法**：把两路电源物理分离（`+5V` 只供逻辑/线圈，`VIN_DC` 只走被测回路），补齐 `U2.VBUS`，保留 21V 软件规格。R1 标注同步改为 `0.1R/2W`（2.5A 时 I²R=0.625W，1W 余量不足）。

### 1.4 仍需实物复核的设计项（非阻断）

1. **继电器触发电平**：固件按 PA2 高电平吸合编写；部分模块为低电平触发。必须先断开负载实测，否则 fail-safe 方向会反。
2. **被测输入负端共地**：`J6.V-` 必须与 MCU 共地；只允许接隔离的低压直流，禁止市电、禁止非隔离电源。
3. **有源蜂鸣器由 3V3 驱动**：若器件额定 5V，3V3 下可能声压不足，建议核对规格。
4. **继电器触点 DC 额定值 / 分流器 2W 温升 / 线材与端子额定值**：需在功率回路实际带载前核验，本图仍是功能连接图，不是投板图。

## 2. 低压实物测试方案（Point 5）

> 以下为可操作的低压（≤ 安全特低电压 SELV，建议 ≤ 12V）验证步骤。**当前环境无法执行物理测试**，方案供具备硬件与可调电源时按序执行；原则："先软件确认、再带电"。

### 2.1 前置（软件侧已完成）
- 固件已用本机 Arm GCC 真实编译：`firmware/GCC_BUILD/build/firmware.bin`（**18576 B，0 警告**，含 IWDG/OLED 错误反馈/功率一致性校验）。
- 保护状态机已通过真实 C 代码单元测试 `tests/protect_tests.c`（TC08；本机无 x86 gcc 时编译检查 + 逻辑移植验证 26/26 断言，需 CI 上执行）。
- 原理图生成器电气自检零告警、`layout check: OK`；`tools/altium/verify_schdoc.py` 文本级网表校验（TC09）通过：25 网络 / 99 引脚 / 101 导线 / 54 标号 / 43 电源端口全部一致。**注意：这不等同于 Altium ERC**。

### 2.2 上电与通信（不接负载）
1. 仅接 `J1` USB 5V 与 SWD/串口，**被测输入 J6 与负载 J4 悬空**；用 5V 限流电源（≤ 0.5A）供电。
2. 确认 OLED 显示 `SELF-TEST...`（若由看门狗复位则显示 `WDG RESET!`）后进入主界面；OLED 缺失时 `oled_ok=0` 跳过渲染，连续 3 次刷屏失败标记掉线，每 5s 低频探活，不阻塞保护节拍。
3. 逻辑分析仪确认 I2C（PB6/PB7）波形，INA219(0x40)、SSD1306(0x78) 地址应答。

### 2.3 采样准确性（低压）
4. 用可调限流电源接入 `J6`（先 5V，逐步到 12V），记录 OLED 的 `V`/`A`/`W` 与温度，对照万用表：误差应 ≤ INA219 LSB（电压 4mV、电流 0.8mA）与 NTC 标定误差。
5. 确认 `g_mon.power = V×I` 与 INA219 硬件 power 寄存器一致（固件已做连续 5 周期交叉校验，超差会判传感器故障切断）。

### 2.4 保护动作（关键，低压模拟）
6. **过温切断**：NTC 靠近热源（或临时降低 `TEMP_CUTOFF_THRESHOLD`）越限，确认继电器断开、蜂鸣器响、状态 `CUT`。
7. **过流切断**：分流回路串入可调负载使电流越限，确认同上。
8. **过压切断**：用可调电源把 `J6` 升到 21V 以上（**不得超过 26V 器件上限**），确认切断；注意此项须在确认 INA219 VBUS 接线正确后进行。
9. **传感器故障切断**：断开 INA219 或 NTC 任一，确认立即 `CUT`；恢复后连续安全采样自动吸合。
10. **阈值闭锁与显式恢复**：触发阈值切断后回到安全态，确认仍 `CUT`（闭锁）；经复位指令调用 `Protect_Recover()` 才解除。
11. **看门狗**：临时拔掉 OLED 或用调试器挂住主循环 >2s，确认 IWDG 复位、自检画面显示 `WDG RESET!`、`R9` 下拉保证复位瞬间继电器断开。
12. **掉电/复位默认态**：反复上下电，用万用表确认继电器触点在上电瞬间不闭合。

### 2.5 安全边界
- 全程限流电源；继电器负载端仅在保护动作验证正确后再接真实负载。
- 任何冒烟/过热立即断电；D1 方向、Q2 极性、R9 下拉先用万用表蜂鸣档确认。
- 低压测试通过且继电器触发电平、分流器温升、触点额定值复核无误后，方可升级到标称电压做最终验收。
